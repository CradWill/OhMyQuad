# OhMyQuad

A website that helps beginner-to-intermediate gym-goers lift safely by clarifying proper exercise form and offering a library of exercises to build effective, injury-free routines.

---

## Why OhMyQuad?

Roughly 25 million people join a gym each year, but only about 12.5% of gym-goers ever work with a personal trainer, and improper form contributes to tens of thousands of gym injuries annually. OhMyQuad closes that gap by giving lifters a free, accessible reference for correct form so they can train efficiently and avoid getting hurt.

| | |
|---|---|
| **What** | Clarifies proper exercise form and offers a library to discover new exercises for effective routines. |
| **Who** | Beginner to intermediate gym-goers aiming to lift safely, refine form, and try new exercises. |
| **Why** | Prevents injury, maximizes training efficiency. |

---

## Features

- **Exercise library** — browse exercises with instructional videos covering proper form and technique
- **YouTube integration** — workout videos are hosted and served via the YouTube API
- **Form guidance** — scripted, research-backed cues for each movement (e.g. squat, deadlift, press)
- **Feedback** — comment section on each workout for user feedback and discussion

---

## Getting Started

### Requirements

- Python 3.x
- YouTube Data API credentials

### Installation

```bash
git clone https://github.com/<org>/ohmyquad.git
cd ohmyquad
pip install -r requirements.txt
```

### Usage

```bash
python app.py
```

Then open `http://localhost:5000` (or your configured port) in a browser to view the exercise library.
